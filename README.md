## 🚀 Getting Started

### Option 1: View the Portal Online
1. Open [portal.html](portal.html) directly in your browser
2. Or visit via GitHub Pages (if enabled)

### Option 2: Download and Use Locally
1. Download `portal.html` from this repository
2. Open it in any modern web browser
3. No installation or server required!

### Option 3: Embed in Your Site
```html
<iframe src="portal.html" width="100%" height="800px" frameborder="0"></iframe>
```
