# Ionity IoT Training Hub

A comprehensive educational resource hub for learning Internet of Things (IoT), Artificial Intelligence (AI), Networking, Encryption, and Modern Software Development.

## Overview

This project provides a curated collection of free and high-quality learning resources for students and professionals looking to advance their skills in modern technology fields. The training hub covers:

- **Internet of Things (IoT)**: From basics to advanced IoT development, protocols, and platforms
- **Artificial Intelligence**: Machine learning, deep learning, and AI for edge devices
- **Networking**: Network fundamentals, wireless technologies, and network security
- **Encryption & Security**: Cryptography basics, applied cryptography, and IoT security
- **Software Stack**: Programming languages, cloud platforms, DevOps, and databases

## Features

- **SEO Optimized**: Comprehensive meta tags for search engine visibility
- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Organized Content**: Resources categorized by topic with clear descriptions
- **Free Resources**: Focus on free and accessible learning materials

## Local Hosting

To run this website locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/AntwerpDesignsIonity/LearningMaterialEngineering.git
   cd LearningMaterialEngineering
   ```

2. Open `index.html` in your web browser:
   ```bash
   # On macOS
   open index.html
   
   # On Linux
   xdg-open index.html
   
   # On Windows
   start index.html
   ```

Alternatively, you can use a local web server:

```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Using Node.js (http-server package)
npx http-server
```

Then navigate to `http://localhost:8000` in your browser.

## Server Deployment

This static website can be deployed to various hosting platforms:

### GitHub Pages
The site is configured to work with GitHub Pages. It will be automatically available at your GitHub Pages URL once enabled in repository settings.

### Other Hosting Options
- **Netlify**: Drag and drop the repository folder or connect via GitHub
- **Vercel**: Import the repository from GitHub
- **AWS S3**: Upload files to an S3 bucket configured for static website hosting
- **Azure Static Web Apps**: Deploy directly from GitHub
- **Traditional Web Hosting**: Upload files via FTP to any web hosting service
