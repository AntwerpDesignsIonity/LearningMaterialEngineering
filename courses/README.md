# Learning Materials Courses

This directory contains organized learning materials across various technology domains.

## Course Categories

### Cloud Platforms
- **Google/Firebase** - Google Cloud Platform and Firebase services
- **Microsoft/Azure** - Microsoft Azure cloud services

### Technology Domains
- **IoT** - Internet of Things courses and tutorials
- **AI** - Artificial Intelligence and Machine Learning
- **IT** - General Information Technology topics

### Engineering
- **Artisan** - Artisan-level engineering courses
- **General Engineering** - Broader engineering topics

## Structure

Each category contains:
- Course materials
- Tutorial links (including YouTube videos)
- Code examples
- Documentation
