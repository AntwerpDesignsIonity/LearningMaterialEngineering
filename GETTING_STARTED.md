## 📚 Step 2: Review Prerequisites

### For IoT Fundamentals (IOT-101)
**Technical Skills:**
- Basic programming in any language (Python recommended)
- Familiarity with command line/terminal
- Understanding of basic networking concepts

**Hardware:**
- Computer (Windows, Mac, or Linux)
- Internet connection
- Raspberry Pi 4 or ESP32 (will be specified in course)

**Software:**
- Modern web browser
- Text editor or IDE (VS Code recommended)
- Will install other tools as part of course

**Not Required:**
- No prior IoT experience needed
- No electronics background required
- Will learn everything from scratch

### For Industry Courses
Each industry course has specific prerequisites listed in its README file. Generally:
- Completion of IOT-101
- Domain knowledge helpful but not always required
- Specific hardware may be needed

## 🛠️ Step 3: Set Up Your Environment

### Install Essential Software

**1. Python 3.8+**
```bash
# Check if Python is installed
python3 --version

# Download from python.org if needed
```

**2. Visual Studio Code**
- Download from: code.visualstudio.com
- Install Python extension
- Install other extensions as needed

**3. Git**
```bash
# Check if Git is installed
git --version

# Download from git-scm.com if needed
```

**4. Clone This Repository**
```bash
git clone https://github.com/AntwerpDesignsIonity/LearningMaterialEngineering.git
cd LearningMaterialEngineering
```

### Purchase Hardware (for hands-on labs)

**Beginner Kit (~$100-150):**
- Raspberry Pi 4 (4GB RAM) + power supply + SD card
- Breadboard and jumper wires
- DHT22 temperature/humidity sensor
- LED kit
- 220Ω resistors
- Push buttons

**Alternative: ESP32 Kit (~$50-80):**
- ESP32 development board
- Breadboard and jumper wires
- Sensor kit (temperature, humidity, motion)
- LED kit
- Resistors and components

**Where to Buy:**
- Adafruit.com
- SparkFun.com
- Amazon
- AliExpress (budget option)

### Set Up Cloud Accounts (Free Tiers)

**AWS IoT Core** (optional)
1. Create account at aws.amazon.com
2. Navigate to IoT Core
3. Follow setup wizard

**Azure IoT Hub** (optional)
1. Create account at azure.microsoft.com
2. Create IoT Hub resource
3. Free tier available

**MQTT Broker** (for testing)
- Use public test broker: test.mosquitto.org
- Or install locally: mosquitto.org

## 📞 Getting Help

### When You're Stuck

**1. Check Documentation**
- Lesson materials
- Lab guides
- FAQ sections
- Resource links

**2. Search Issues**
- GitHub Issues tab
- Someone may have same problem
- Check closed issues too

**3. Ask Community**
- GitHub Discussions
- Be specific
- Show what you tried
- Share error messages

**4. Troubleshooting Labs**
- Follow verification checklists
- Check connections
- Verify software versions
- Review logs

### Common Issues

**Hardware Not Working**
- Check power connections
- Verify wiring with diagrams
- Test components individually
- Check for shorts

**Software Errors**
- Read error messages carefully
- Check library versions
- Verify Python/Node version
- Check file paths

**Connectivity Issues**
- Verify network connection
- Check firewall settings
- Test with simple examples
- Use diagnostic tools
