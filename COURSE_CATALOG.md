# Course Catalog

## Complete IoT & AI Training Program

### Program Overview
This comprehensive training platform provides end-to-end education in IoT and AI technologies with specialization tracks for multiple industries.

**Total Duration**: 72+ weeks (360+ hours)
**Delivery**: Self-paced online learning with hands-on labs
**Certification**: Available upon course completion

---

## Foundation Courses

### 1. IoT Fundamentals ⭐ REQUIRED
**Code**: IOT-101  
**Duration**: 8 weeks (40 hours)  
**Level**: Beginner  
**Prerequisites**: None

**What You'll Learn:**
- IoT architecture and components
- Sensors, actuators, and microcontrollers
- Communication protocols (MQTT, CoAP, HTTP)
- IoT security fundamentals
- Cloud platforms (AWS, Azure, Google Cloud)

**Hands-On Labs:**
- Development environment setup
- Sensor interfacing
- MQTT messaging
- Cloud connectivity
- Basic IoT project

**Assessment**: Quiz + Practical project

## Frequently Asked Questions

**Q: Do I need a technical background?**
A: Basic programming knowledge is helpful but not required for IOT-101. Industry courses may require domain knowledge.

**Q: Can I take courses out of order?**
A: IOT-101 is prerequisite for all others. Industry courses can be taken in any order after foundation.

**Q: Are there live classes?**
A: Currently self-paced only. Live sessions may be added in future.

**Q: What if I get stuck?**
A: Use community forums, GitHub discussions, and troubleshooting guides. Community support available.

**Q: Can I contribute to course content?**
A: Yes! This is open source. Submit improvements via pull requests.

**Q: Are certificates recognized by employers?**
A: While not accredited, completing this curriculum demonstrates practical IoT skills. Portfolio projects are valuable for job applications.
